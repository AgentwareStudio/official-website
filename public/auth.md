# Auth.md - Authentication Policy for AI Agents

This site is a publicly accessible website. All public pages and content are freely accessible.

## Authentication

- **Scheme**: None
- **Requirement**: No authentication is required to access public content and documentation.
- **APIs**: No public API endpoints are currently available.

## Agent Registration

- **Registration**: Not required. AI agents do not need to register, create an account, or obtain an API key.
- **Login**: No login credentials or OAuth flow needed.
- **Access**: Free and open for retrieval and reading.

## Rate Limits & Contact

- **Rate Limits**: Standard fair-use policies apply via Cloudflare edge protection.
